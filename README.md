# Machine-Learning-in-Predictive-Cardiology

This is my 2024 UCSD COSMOS Cluster 12 (Machine Learning: Can we teach a Computer to Think?) Final Project Analyzed data on cardiovascular disease using different models: logistic regression, kNN, MLP, and CNN Programmed additional input functionality where users can enter their own health data to make our results more useful Returned an analysis and prediction of an individual's risk for cardiovascular disease

Cluster 12 Final Project Honorable Mention
