# Machine Learning in Predictive Cardiology

Final project for UCSD COSMOS Cluster 12 (*Machine Learning: Can We Teach a Computer to Think?*), summer 2024. Awarded Honorable Mention.

## Overview
Analyzed data on cardiovascular disease using different machine learning models: logistic regression, kNN, MLP, and CNN models. Predicts cardiovascular disease risk from patient health data. Users can enter their own values to get a personalized risk estimate and analysis.

## Data
[Risk Factors for Cardiovascular Heart Disease](https://www.kaggle.com/datasets/thedevastator/exploring-risk-factors-for-cardiovascular-diseas) (Kaggle): about 70,000 patient records with features such as age, gender, height, weight, blood pressure, cholesterol, glucose, smoking, alcohol use, and physical activity. The target is whether the patient has cardiovascular disease.

## Models and Results
| Model | Accuracy |
|---|---|
| Logistic regression | 72% |
| kNN | 72% |
| CNN | 73% |
| MLP (5 hidden layers, ReLU) | 74% |
